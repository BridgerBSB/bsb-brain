# AstrosEDU course builder

A reusable brief that turns a topic into a course: outline with stage gates, lessons that
each end in check questions, a "common mistakes" lesson built from our rule-file bug
histories, and a quiz bank for the shipped quiz system. It must read the matching canon note
first so the course never contradicts GC2 definitions. Pilot on Hitting Module 7 (Metrics &
Tech Literacy). Live tutor mode is a later, separate step.
