# Three-view bat path comparison card

One hitter, two windows (before/after a change, or hitter vs level average): side, top and
catcher's views of the bat path with the contact point marked, plus a one-row-per-window
table (bat speed, AA, swing length, direction, tilt, contact depth). Reference layout =
Kozak's Volpe visuals. Data start: `sql-queries/bat-trajectory-discovery.sql`. Belongs with
the PARKED swing cards; use this as their layout reference when they un-park.
