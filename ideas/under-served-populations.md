# Under-Served Populations (Tier 14)

Closes the coverage holes: position-player arm projection, baserunning value beyond leads (first-to-third rate, extra-bases-taken), and a non-tracking fallback estimator for sparse DSL/FCL venues. We under-evaluate two real tools (arm and legs) where the cameras are not, which can mis-rank prospects whose value is in those tools.
