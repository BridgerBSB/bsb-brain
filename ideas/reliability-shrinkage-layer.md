# Reliability / Stabilization + Empirical-Bayes Shrinkage (Tier 0A)

Per-metric, per-level stabilization atlas plus empirical-Bayes shrinkage: find the sample n* where each metric becomes trustworthy at each level, then shrink displayed values toward the level/age prior (Beta-Binomial for rates, Normal-Normal for continuous). Replaces flat hard gates (n>=3, >=30/pitch) that paint 35-PA hot streaks green. Lowest effort and highest value on the whole list, and it hardens every existing tracker plus the LightGBM features.
