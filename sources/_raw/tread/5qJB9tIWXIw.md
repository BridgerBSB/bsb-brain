# Loading the Hinge: How to Improve Pelvic Loading

## Description

Feeling stuck in your career? Go here: https://treadathletics.com/connect/5qJB9tIWXIw

-------------------------------

Don't have access to a Core Velocity Belt? Look no further, here's a great way to "load the hinge" with this simple hack. The ability to control the pelvis throughout the drive phase or "riding the center" is an essential piece of a high velocity lower half, attacking this concept head on with feels progressions is only half the puzzle. Being able to have the "feel" translate directly to the pitching delivery is the endgame, utilizing this simple constraint with added resistance is a great place to start!
