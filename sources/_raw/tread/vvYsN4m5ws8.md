# How To Read Pitch Inflection Points For Arsenal Evaluation

## Description

Feeling stuck in your career? Go here: https://treadathletics.com/connect/vvYsN4m5ws8

-------------------------------

Performance Coach Tyler Zombro explains how to read inflection points in order to evaluate a pitcher's arsenal. 

Seeing metrics in Velocity, Vertical Break, Horizontal Break, and Vertical Approach Angle for each pitch and comparing it with Whiff Rate and WOBA will help you decide which pitches may need some more work or which are already considered elite. 

This is an intro video to the upcoming inflection points series that will go over 6 different pitches.
