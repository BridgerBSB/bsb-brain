# Velocity Program: Throwing-Related Work

## TL;DR
- Intro to Driveline's 2011 velocity program: pitchers should learn to throw first and pitch second, using a product kit (Plyo Balls, weighted baseballs, J-Bands, wrist weights) and embedded videos with no written instruction, ending in a pitch for the "5-7 MPH" program.
