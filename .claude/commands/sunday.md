description: Weekly review — read the week, return one win / one friction / one change
argument-hint: [optional]

Close the week. Read the **last 7 days** of `05-daily/` notes plus any new or
changed notes in `projects/`.

**WRITE-ZONE ONLY** (write to `personal/reviews/`, never `rules/` or `memory/`).

1. Extract: what got **done**, what **didn't** (and why), recurring
   **themes/patterns**, and **next-week priorities**.
2. Write a weekly review note at `personal/reviews/YYYY-Www.md` (ISO week number —
   create the `reviews/` folder if needed). Link the daily notes it summarizes
   with `[[wikilinks]]`.
3. Output **exactly**:
   - **One win**
   - **One friction**
   - **One thing to change next week**
4. **Propose** (don't write) any decisions that should become memory facts.

This review becomes next week's starting context for `/context` and `/today`.
