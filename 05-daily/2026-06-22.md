# 2026-06-22

**For future Claude:** Built out the [[Pitch Similarity]] tool inside [[Arm Farm]] end-to-end — z-score "Similarity %" scoring, arm angle (+ a daily pin to make it fast), per-pitcher movement-profile plots, and a string of UI fixes from live testing.

## Top 3
- Ship the [[Pitch Similarity]] z-score "Similarity %" mode + arm-angle metric.
- Kill the 3-min cold load (arm angle) with a daily precompute pin.
- Fix the live-test bugs (profile dropdown reset, decimals, layout).

## Shipped
- **Similarity % (z-score) mode** as an opt-in toggle — pure top-N ranking, pool σ per pitch type, `100·e^(−dist/√N)` score. Default "Tolerance bands" untouched.
- **Arm Angle** added as an 11th match metric (Brodie formula, >90° cap).
- **Daily arm-angle pin** (`zbridger/arm_farm_arm_angle_{year}`) + `scripts/pin_arm_angle.py` + `connect_pins_arm_angle/` deploy bundle. Pinned all 9 years (2018–2026, ~24.3k pitcher-seasons) on the work laptop → arm angle now instant.
- **Per-pitcher movement profile** — dropdown picks one comp; ellipse-per-pitch-type plot with the anchor's ellipses dashed-navy, arm-angle rays (solid=comp, dotted=anchor), optional anchor-dots toggle.
- **UI polish**: rank #, headshots, green→red Sim% gradient, one-decimal formatting (spin 0 dp), metrics-then-deltas column order, anchor shape table below the Find button, two-column Match-on metrics, detailed z-score "?" tooltip.

## Wins
- The arm-angle infra audit confirmed we already precompute arm angle per pitcher-season in the tracker pin (league-wide) — reused the proven pin/deploy template instead of building from scratch.
- Pin job ran clean on the work laptop: 24,299 pitcher-season rows across 9 seasons.

## Friction
- Connect deploy of the pin notebook failed its first auto-render: SSPI/Kerberos error = `DB_USER`/`DB_PASS` Vars not set yet (falls back to Windows auth on the Linux box). Fixed by guarding the notebook to skip cleanly when creds are absent. → durable lesson: **lead with the required Connect Vars**.
- A few rounds of "you didn't fully explain X in chat" / scope mismatches — built standalone first when it should've been an Arm Farm tab; buried the Connect Vars step.

## Notes & ideas
- v2.1 / v3 roadmap captured in `bullpen-report/docs/PITCH_SIMILARITY_ROADMAP.md`: Bauer units, spin axis/tilt, Mahalanobis (correlated metrics), era normalization, arsenal usage weighting.
- Methodology grounded in: tjStats, Model 284, Baseball Analytica, FanGraphs Pitch Arsenal Scores, Baseball Savant — all do normalize-then-Euclidean nearest-neighbor (our baseline is the standard).

## Reflection
Long iterative loop with real live-DB testing on the work laptop driving each round of fixes — the build → push → test → feedback cadence worked well once the app was deployed and fast.
