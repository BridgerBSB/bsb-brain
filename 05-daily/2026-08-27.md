## Session - a saved note came back blank (EOY, session c712)

Tina relayed Daniel Gonzalez: notes typed, each box saved, "but when I go back
to the person, there is no note." It was never the save. The pin had every note.
Streamlit collects the state of any widget it did not draw on a run, and since
Aug 20 the boxes are keyed per player, so opening the next guy dropped the
previous one's text - while the "already hydrated" marker, a plain key, survived
and blocked the re-read.

**Daniel's all-clear was the confirmation, not the refutation.** "I had to
refresh the whole page for it to pop back up" - a refresh starts a new session,
which is the only thing that clears that marker. Worth remembering as a shape:
when a user reports a problem solved by a full reload, the reload is a clue, not
a closure.
