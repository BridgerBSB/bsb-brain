**Four things worth remembering:**

1. **A name can already be taken.** "Proj" looked like a free label for
   stuffrelvelloc; `postgame_data.py:125` already binds it to `ppg.fb_grade`.
   Shipping the rename would have put one label on two quantities on the same
   card. The tell was Zac's own next sentence - "proj needs to [be coloured]" -
   which only makes sense for a metric that already has a pool. It did.

2. **Two frames, two coordinate conventions.** `enrich_pitches` flips
   break/release/plate_x to the pitcher's view. The SEASON frame is raw; the
   GAME frame is enriched. Moving the tab from one to the other inverted the
   tilt sign, and both directions look completely plausible on a card.

3. **A control that did not exist cannot be wrong.** `get_game_sessions` has no
   season predicate - harmless for years, because you could only pick ONE
   outing. Adding Select All turned it into 11,036 career pitches ranked against
   one season's pool. New affordances make old assumptions load-bearing.

   `NameError` in a branch nothing could reach, and a render mock that had been
