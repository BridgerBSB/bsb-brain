Built the org-wide Level x Domain cockpit and made it the PD Goals landing view.
Commits `372ca801` (cockpit + st.tabs -> keyed st.radio), `a0d9618d` (cockpit ->
Player hand-off), `fb236058` (Int64 fix), plus a LINEAGE entry. 23 tests pass.
No new pin, no new SQL, no new metric — it re-arranges the compliance detail the
Goal Compliance view already reads.

Decisions made:
- `st.tabs` retired. Verified safe FIRST with an AST cross-reference of
  assigned-vs-used names per tab block (zero cross-view deps) — because only the
  selected view's body runs under `if` blocks.
- Matrix + domain bars are NAVIGATORS: scoped by Level + Type only, Domain just
  highlights. Scoping the bars by Domain too left 5 of 6 reading "- (0/0)".
  Caught on a render, not by reasoning about it.
- Open-player is a picker + button, not `st.dataframe(on_select=)`. Built the row
  click first, couldn't get it to register headless (canvas), wouldn't ship an
  interaction I hadn't watched work.

version `20260730T113236Z-01996`. Notably `blank season = 0` and

  serving OLD code and you screenshot a stale build. Cost two false conclusions.
  Kill via PowerShell Get-NetTCPConnection | Stop-Process.
