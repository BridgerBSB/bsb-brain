# 2026-08-18


## Session - 2027 Projection Magnet Board (built + live on work laptop)

New standalone app at repo-root `magnet-board/` on `feature/pd-goals`. FastAPI +
SQLite + vanilla JS. ~230 HOU players as draggable magnets in a 7-level x 5-group
grid; dragging asserts "this is where he opens 2027". Two users, placements
persist and are shared.

Commits: `b2daeea5` contract - `0f8ffeab` v1 - `1a0920ea` README -
`0e700b9d` seeder + showcase - `51ce725e` SP/RP rows. 231 tests pass.

**Decisions Zac made:**
- Org-wide, not the DSL-only shape of cperez's board.
- NOT going on Posit. That is the load-bearing one: off Connect, SQLite gives
  real row-level INSERT and the whole pin whole-file-rewrite clobber class
  simply does not apply.
- Rows are SP/RP by ROLE, reversing an earlier RHP/LHP call.
- "we arent even looking for loft and tilt" - that metric question is dead.

**The thing worth remembering:** `PP_MASTER.POSITION_LK` encodes handedness AND
role in one code (RHS = right-handed STARTER, RHR = right-handed RELIEVER). I had
flagged SP-vs-RP as the hard data problem needing a GS/G derivation off a box
table. It did not. Same field, one dict.

**Two silent blockers** caught by review agents, both fixed and regression-tested
after being re-introduced on purpose to prove the tests go red: a batch dedupe
that silently reverted the user's last drag, and a `moved` flag that rendered
every magnet on a fresh board orange (the tautological-display class again).

**Render caught what tests could not:** the UNDECIDED pile pushed the grid below
the fold, and HTML5 drag does not auto-scroll, so you could not drag into a cell
you could not see.

**Work-laptop gotcha worth keeping:** `python -m venv` there routes through
`uv.exe` and trips the Astros IT allowlist. Skip the venv entirely -
`pip install fastapi uvicorn` to user site-packages is all it needs.

Also talked hosting + stats: whole org with 25 stats + 25 percentiles = 45 KB
gzipped, so ship one payload and never query SQL Server on interaction. GC2 is
fast because the expensive thing already ran and became a column. That analysis
lives only in the conversation so far.
