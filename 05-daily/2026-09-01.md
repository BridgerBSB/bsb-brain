**Three defects I shipped and then caught:**
- A fixed "dock" of the release boxes painted OVER the magnet being dragged.
  Measured it with `elementFromPoint` rather than guessing - the drag was never
  blocked, it was covered. Replaced with edge auto-scroll, which is what Zac
  asked for in the first place.
- The CSV importer built each player field by field and did not name
  `r5_first_year`/`mnfa_year`, so both were dropped on import. The query emitted
  them, the magnet asked for them, nothing joined the two.
- `milb_fa` was 0 for all 282 players - I shipped a chip that could never draw,
  which is the exact class blocking rule #19 exists to prevent. Zac's check
  query is the only reason we found out.

**Two access paths that failed OPEN:**
- `admins.role` DEFAULTs to `'admin'` and `upsert_admin` does not write it, so a
  coordinator whose level did not land became an ADMIN - more access than asked
  for. Now read back and disabled if it did not take.
- With no `RESEND_API_KEY` the mailer writes a file and returns ok:True. Fine
  for an invite; wrong for a first password, which exists nowhere else. The
  page said "added" and nobody could sign in.
