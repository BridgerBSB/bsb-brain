# Daily Notes

One note per day: `YYYY-MM-DD.md`, created from `templates/daily.md`.

- Written by **`/log`** (evening dump → structured note).
- Read by **`/context`** (where did I leave off) and **`/today`** (morning briefing).
- Weekly reviews roll up here too — written by **`/sunday`** into `personal/reviews/`.

This is a **write zone**. Capture freely.
