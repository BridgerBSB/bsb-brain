## v1 SCORING LOCKED — Jun 25 2026 (commit `c5d8ed95`), UNTESTED on live DB
Curve resolved with Zac and shipped. Design doc §9 has the full list.
- **Damage field = Nadaraya–Watson RATE** (local-avg xwOBAcon = `KDE(w=xwOBAcon)/KDE(w=1)`), Scott's-rule adaptive blur, 5%-of-peak density floor, ≥15 BBE. `d` = percentile-normalized field value at each offered pitch (median 0.5, multi-hot-spot safe).
- **FIELD decoupled from GRADE (Zac, Jun 25):** field = his **most recent ~500 BBE** across levels/seasons (stable trait); **grade + pre-2K/2K maps = selected `--year` ONLY.** `grade_one_hitter(score_df, bounds, field_pitch_df=...)`; script `_collect_for_grade` walks seasons for the field, scores the year. (`--max-bbe` default 500; `_recent_pa_pitches`/`--max-pa` REMOVED.)
- **Score is pure LOCATION** — no Execution term (whiff/weak/damage don't change the score). Only outcome rule = the 2-strike chase.
- **TAKE = GEOMETRIC, csc DROPPED from the score:** take a **ball** → `+outside_frac` (0 at edge, **+1** in dirt); take a **strike** → `−(0.3 + 0.7·d)` (cold-corner ≈ −0.3, damage meatball ≈ −1); **+2 strikes** on a taken strike → extra **−0.3** (called-K). Constants `TAKE_STRIKE_BASE=0.3`, `TAKE_DAMAGE_W=0.7`, `TWO_STRIKE_TAKE_W=0.3`. csc now drives the DISPLAYED O-Sw/Z-Sw only. Geometry = zone + 1 ball radius (width ±0.83, height 0.27h..0.535h ±0.121) via `is_strike`/`outside_frac`.
- **SWING base = `2d−1`.** **2-strike + IN-ZONE swing is REWARDED:** `max(2d−1, PROTECT_REWARD=0.4)` — protecting the zone ≥ +0.4, worth more in his damage zone; limited to in-zone (was `max(net,0)`, no reward). 2-strike chase: whiff `−outside_frac` (cardinal sin), foul/contact survival credit ≤ +0.2.

**TWO CODE FINDINGS (read the code, don't repeat the wrong mental model):**
1. **The 4-BBE@0.4ft gate is DISPLAY-ONLY.** `DamageField.grid(min_bbe,radius)` only blanks heatmap CELLS (image 661). Scoring `d` comes from `field.value()`→`_rate()` gated by `den_floor`=5%-of-peak-KDE — NOT the grid count. So bumping the grid gate does NOT move points. Fix = push a real BBE-count gate into SCORING → shipped `DamageField.value_gated(px,pz,min_bbe,radius)` (the scoring twin).
2. **The −0.40 chase-whiff (img 660) is partly a PERCENTILE-TIE artifact.** `d` = `argsort().argsort()` percentile rank of offered pitches (median 0.5 by construction). Out-of-zone pitches all have raw=0 (below den_floor) → a big block of tied zeros → ranking SPREADS them d≈0..0.3+. So a genuinely-cold chase ranked to d=0.30 → `2d-1`=−0.40. Geometry term (#2) sidesteps ties (chase = chase regardless of ranking).
