3D spray chart dimensions must be identical across OF and IF individual pages. Always use Minute Maid polynomial fence (ALL levels, ALL charts — never MiLB cosine). z-range [0,200], aspect ratio x=1/y=1.2/z=0.4, camera eye (-1.5,-1.5,0.8).

**Why:** User explicitly rejected an IF-specific zoom (shorter foul lines, infield grass arc, reduced z-ceiling). The full field gives consistent spatial context regardless of position — infield plays should be visible in the context of the whole field, not zoomed in.

**How to apply:** Never customize spray chart field dimensions per position type. If a new position-specific page needs a spray chart, copy the OF version exactly.
