name: Summary tables for status reports
description: User loves table-format status reports after audits/fixes — always report back this way
type: feedback
---

When reporting results of an audit, health check, or batch of fixes, ALWAYS use a simple markdown table with columns like Issue | Fix | Status. The user called this "spectacular" and wants it across all branches.

**Why:** Quick visual scan of what's done, what's broken, what needs attention. No wall of text.

**How to apply:** After any multi-item fix session, close with a summary table. Use status values like FIXED, VERIFIED, BY DESIGN, NOTE, PENDING.
