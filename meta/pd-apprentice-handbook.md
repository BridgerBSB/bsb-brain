PD Apprentice Handbook — the 192-page onboarding doc for a new Player Development analytics apprentice working under Zac Bridger (PD analyst). Role is SQL-heavy: build reports/metrics/visuals, run one-off coach queries, hold three-surface parity, keep `.claude/rules/` accurate.

## Chapters
1. **Orientation** — role, the 4 apps, two-laptop setup, weekly cadence, who's who.
2. **Stack & Workflow** — Python stack, DB stack, 4-worktree strategy, dev cycle, Posit Connect, PDF+Slack pipeline.
3. **Database Tour** — connection, schema, the 5 daily tables, ID cross-walk, dual-join (BLOCKING), level/sched codes, BIT trap.
4. **GroundControl2 & Our Deviations** — what GC2 is, the 4 big GC2 metrics, the 7 deliberate divergences, bug-vs-divergence, gcOBA worked example.
5. **Metric Catalog** — codebase metric guide, GC glossary, key formulas.
6. **Data Cleaning Canon** — BIP filter chain, bat-speed helper, 6-term Tier 1 fielding gate, BIT casting, ignore_flag, never-round-until-display (all BLOCKING).
7–10. **The 4 apps** — Barrelsville (hitting), Arm Farm (pitching), Intangibles (BR/OF/IF/C), PD Engine (Goals/Org Board/Transition).
11. **Cross-App Patterns** — three-surface parity, multi-level rollup weights, dual query path, KPI pool-then-aggregate, in-app submission, V-column video fallback, PA-gate vs wOBA denom.
12. **SQL Query Playbook** — `sql-queries/`, skeletons, HOU one-off template, 5-step perf diagnostic.
13. **Delivery Infrastructure** — Logic App pipeline, channel routing, parquet pins, Connect-scheduled jobs.
Plus **How-To Recipes**, **Reference** (rules index, acronyms, URLs), **Collaborating with Teammates** (git flow, PR conventions, first PR).
