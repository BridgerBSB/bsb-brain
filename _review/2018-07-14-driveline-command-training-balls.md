# Driveline Command Training Balls

## TL;DR
- Command is trained as a skill with a set of over/underweight and over/undersized balls, not just by repeating normal throws.
- The ball type is matched to the miss: overload and oversized balls for high misses, underload and undersized balls for glove-side misses.
- The balls are thrown in a randomized sequence, starting at the lowest skill level and advancing from there.

## Claims
- [00:00](https://youtu.be/25UbM3Ojm5w?t=0) The command balls are a system of overload and underload balls plus oversized and undersized balls, used to develop command in pitchers at Driveline.
- [00:00](https://youtu.be/25UbM3Ojm5w?t=0) A pitcher struggling with command starts a progression; the command ball order is randomized based on skill level, and players start at the lowest level and advance.
- [00:00](https://youtu.be/25UbM3Ojm5w?t=0) For an arm-side high miss, the pitcher throws overload and oversized baseballs, which are the ones that tend to go high. The balls are then sequenced in a different order to correct for the miss.
- [00:00](https://youtu.be/25UbM3Ojm5w?t=0) For a slider missing glove side, the pitcher throws underload and undersized balls in a random progression to perfect that skill.
- [00:00](https://youtu.be/25UbM3Ojm5w?t=0) The description states "Command is a skill. Train it as such." and that the set is sold in the Driveline shop.
