Runs Above Replacement — a player's total run value over a freely-available replacement-level player, the common currency for cross-position, cross-level comparison. The hitter version aggregates [[orp-bat]] + [[orp-br]] + defense; the pitcher version sums from PRS (Pitching Runs Saved).

Used in amateur/asset-value work via the MLE projection tables.
