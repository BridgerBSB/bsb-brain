# xwOBA (expected wOBA)

Expected weighted on-base average — models a batter's *deserved* offensive value
from contact quality (EV, LA) + outcome probabilities, stripping luck. xwOBAcon =
the contact-only variant.

**Used in:** [[og-pena]] (xwOBAcon on Peña's contact), [[personal-bsbres]]
(hitter-metric templates).
**Related:** [[statcast-pipeline]] · [[strike-zone-kde]] · barrels/sweet-spot.
**Astros canon:** [[xwoba-canonical]] — the BLOCKING rule that every Astros xwOBA
value must match GC2 within ±0.001 (per-PA league weights, IBB-as-walk). The
personal version is the public-Statcast cousin of this.
