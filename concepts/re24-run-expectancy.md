# RE24 / run expectancy

The 24 (actually 8 base × 3 out) base-out states → expected runs to end of inning
(FanGraphs lookup). The backbone of any *value* framework: a decision's worth =
ΔRE between the states it moves you to. Feeds **xRV** (expected run value).

**Used in:** [[send-from-2b]] (xRV of every send/hold call) → [[send-hold-decisions]].
**Related:** [[lightgbm-baseball-modeling]] (P(success) feeds the EV calc).
**Astros tie-in:** the skill-vs-luck framing maps onto the
[[2h-1to3-run-attribution-status|BR run-attribution work]] and any postgame
send-decision audit. Lookup table is league-generic → directly portable.
