# Astro World — Hitting Tab Structure (approved v2)

The locked section layout for the **Hitting** domain in Astro World. Started as a 1:1
mirror of Camden Quick's Pitching spine + 3 additions (v1); **consolidated to v2** after
Sam Niedorf's review (combine overlapping sections). Each section maps to a module/note in
[[pd-onboarding-curriculum]] (staging layer; one module → one Astro World lesson).

**Voice rule (BLOCKING):** Astros hitting principles only — coach/player-facing.
**Never name Driveline / HTKCH / any source** in the app.

## Section order (live in app, v2)
0. **Hitting Philosophy & Org Alignment** — function over aesthetics, dev cycle, player-owned *why* — Module 0, [[meta/skill-dev-principles]]
1. **Hitting Structure** — gameday & non-gameday routines, daily priming, scheduling/workload — Module 4, [[training-implements]]
2. **Game Planning & Advance Process** — approach archetypes (Zone/Target/Guess), build from arsenal·usage·location, advance reports + opposing-pitcher heatmaps, in-game adjustments — Module 8, [[big-3-hitting]]. *(v1 merge of In-Game Strategy + Hitter-by-Hitter Game Plan + Advance Scouting.)*
3. **Hitter Evaluation & KPIs** — Big 3 profile + KPIs (gcOBA, SwDec, Damage%, Top-8th EV, Smash Factor, AA/PoC), goals, reviews, profiling, hist vs recent, criteria-based promo/demo; **carries the bat-speed → strength cross-link** — Module 7 + [[big-3-hitting]], [[swdec]], [[xwoba]]
4. **Mechanics & Biomechanics** — phases/checkpoints (load→stride→swing→impact), segments & ground force, bat path (attack angle, H/V bat angle, on-plane) — Module 5, [[hitting-biomechanics]]
5. **Training Environments, Compensations, Flaws & Drills** — blocked→random + perception–action, in/off-season periodization, implements, **plus** the 8 flaws by phase + implement→flaw map + drill catalog — Modules 4 & 6, [[swing-flaws-programming]], [[drills-programming]], [[training-implements]]. *(v2 merge of Training + Flaws & Drills.)*
6. **Technology** — TrackMan/HitTrax/Rapsodo, Blast/Diamond Kinetics, K-Vest/mocap, force plates, Edgertronic, Hawkeye — Module 7. *(renamed from "Hitter Technologies".)*
7. **Communication, Buy-in & Scaling** — teach the *why*, ownership, cueing, scaling across affiliates — Module 9, [[meta/skill-dev-principles]]
8. **FAQs** — comprehension gate from [[hitting-coach-question-bank]] / quiz bank
99. **Job Description** — pinned at domain bottom (all domains carry one)

## Changes from v1 → v2 (Sam's review)
- **Merged** In-Game Strategy + Hitter-by-Hitter Game Plan + Advance Scouting → §2 (all Module 8 / game planning).
- **Dropped** standalone "Strength & Physical Assessment" (S&C owns it); kept only the bat-speed→strength cross-link in §3.
- **Cut** lineup-construction / platoon / PH-leverage content (manager/roster strategy, not hitter development) — not in the hitting tab.
- **Merged** Training + Compensations/Flaws & Drills → §5.
- **Renamed** Hitter Technologies → "Technology".
